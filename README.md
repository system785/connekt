# ООО «Коннект» — корпоративный сайт

Современный адаптивный сайт компании **ООО «Коннект»** — проектирование, монтаж и обслуживание инженерных систем зданий и сооружений (Санкт-Петербург, работа по всей России с 2007 года).

## Демо

Сайт опубликован через GitHub Pages: **https://system785.github.io/connekt/**

## Структура проекта

```
.
├── index.html            # О компании (главная)
├── services.html         # Услуги
├── projects.html         # Объекты
├── documents.html        # Документы и отзывы
├── sotrudniki.html       # Сотрудники
├── vakansii.html         # Вакансии
├── kontakty.html         # Контакты
├── privacy.html          # Политика конфиденциальности
├── 404.html              # Страница ошибки
├── assets/
│   ├── css/style.css     # Стили (дизайн-система, адаптивность, анимации)
│   ├── js/main.js        # Навигация, анимации при скролле, модальные окна, формы
│   └── images/           # Логотип, иконки, фото, документы
├── robots.txt            # Директивы для поисковых роботов
└── sitemap.xml           # Карта сайта
```

## Технологии

- Чистый HTML5, CSS3 и ванильный JavaScript — без сборки и зависимостей.
- Адаптивная вёрстка (mobile-first, CSS Grid/Flexbox).
- Анимации появления при скролле, плавные переходы, анимированные счётчики, бегущая строка логотипов.
- Поддержка `prefers-reduced-motion`.
- SEO: семантические заголовки H1–H4, мета-теги, Open Graph, микроразметка JSON-LD (Organization, LocalBusiness, BreadcrumbList, JobPosting), `robots.txt` и `sitemap.xml`.

## Публикация на GitHub Pages

1. Создайте репозиторий и загрузите файлы в ветку `main`.
2. В настройках репозитория: **Settings → Pages → Source → Deploy from a branch → main / (root)**.
3. Сайт будет доступен по адресу `https://<username>.github.io/<repository>/`.
